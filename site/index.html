A plan you can watch and steer.

Rudder is not a transcript UI. You give it a goal, it decomposes the work into a task DAG, and the orchestrator pane shows the plan and every node's status live. Refine the plan by chat, add tasks while it runs, then review and merge.

orchestrate

Plan into a DAG

Describe a goal once. A read-only planner inspects the repo and emits a task DAG with typed hard and soft dependencies, which you refine in chat before it launches.

parallel

Agents in jj workspaces

Ready nodes run Claude Code and Codex in parallel, each in its own isolated jj workspace, so they build concurrently without trampling the main checkout.

review

Review and merge

Watch a live jj diff of any node, merge clean work mechanically, and let an AI resolver integrate conflicts. Merging a parent unblocks its children automatically.

Three panes, three jumps.

Option-1, Option-2, and Option-3 always mean Agents, Worker, and Task. The Worker pane still belongs to Claude or Codex, so dashboard commands from there start with the Ctrl-W leader.

Option-1 Agents list Pick a run, move with j/k, then review, merge, rename, or delete.
Option-2 Worker terminal Talk directly to Claude Code or Codex. Tab and prompts stay native.
Option-3 Task box Start a plan, answer planner questions, or add work to a running DAG.
